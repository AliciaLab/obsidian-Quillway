# Quillway

追踪中文小说写作过程，自动记录你小说每一段增删字数、不同版本，用于回顾创作历史、检查字数存留率。

## 功能

- **拼字竞速**：与虚拟拼字对手进行速度比拼。你可以自定义对手的昵称和打字速度，看看自己能否赶上对手。

- **字数统计**：在 Obsidian 状态栏实时显示当前写作区域的字数，按照 Microsoft Word 的字数统计规则计算。

- **时速统计**：分别统计原始打字时速和实际写作时速。原始时速反映输入文字的速度，实际时速则扣除删除的文字，反映最终保留下来的写作效率。

- **写作数据统计**：记录累计输入字数、删除字数和最终保留字数，并计算文字留存率，帮助你了解写作过程中产生了多少文字，以及最终留下了多少。

- **段落修改追踪**：逐段记录写作区域内的文字增删变化，统计每段新增、删除和保留的字数，以及对应的留存率。

- **段落版本记录**：保存每段文字在修改过程中的不同版本，方便回顾内容从初稿到当前版本的变化。

- **Markdown 报告导出**：将当前笔记的写作数据、段落修改记录和历史版本导出为 Markdown 文件，保存在原笔记所在目录。

- **隐藏分隔标记**：一键隐藏用于划定写作区域的 `···` 分隔行，让编辑器保持整洁，同时不影响写作追踪。


## 使用

1. 启用插件后，在笔记里写两行单独的 `···`，把你的写作内容放在这两行之间：

   ```markdown
   ···
   这里是正文。
   ···
   ```

2. 点击功能区的图标，打开面板。
3. 点击计时按钮，开始和停止写作计时。
4. 点击总览旁边的小眼睛图标，隐藏编辑器里的 `···` 标记行。
5. 点“导出 Markdown”，在当前笔记的同目录生成一份追踪报告。
6. 在插件设置里可以修改对手昵称、对手时速，以及是否在状态栏显示字数。

## 说明

- 只会追踪前两行 `···` 之间的内容。
- 数据统计只统计开始追踪后输入的字，打开文件时已经存在的内容不计入输入。
- 英文字母不参与统计。
- “重置”会清空当前文件的累计数据和总览，重新从当前正文开始记录。
- 仅支持 Obsidian 桌面端。

## 安装 
- 将装有main.js、style.css、mainfest.json的quillway文件夹，放进plugin目录下。
- 使用BRAT插件拉取地址。
