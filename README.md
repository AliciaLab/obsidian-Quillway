# Momentum

给中文小说写作用的 Obsidian 插件。
它能自动记录你小说每一行增加的字、删掉的字，每一段话的增改版本。
方便估计写作效率，回顾自己的创作历史，检查自己的字数存留率。

## 功能

- **拼字竞速**：提供一名匀速创作的虚拟拼字对手，他将以特定速度创作小说，与你进行写作PK。
- **字数统计**：在状态栏里显示一个字数统计模块，以 Word 的中文计数规则计算字数。
- **时速统计**：分别以原始时速和实际时速进行统计，原始时速指无删改状态的打字速度，实际时速则计算删改的字数，统计实际的写作时速。
- **数据统计**：显示累计输入、累计删除、最终保留和留存率。
- **写作总览**：保留区域内每一段的删改历史，新增和删除的字数都会统进进面板，并计算每一段的增字、删字和存留率。
- **修改版本**：记录每一段话的删字、增字记录和由此产生的不同版本。
- **导出 Markdown**：把当前文件的统计、总览和版本记录导出到笔记同目录。
- **隐藏分隔行**：用于标记写作区域的 `···` 行可以一键隐藏。

## 使用

1. 启用插件后，在笔记里写两行单独的 `···`，把你的写作内容放在这两行之间：

   ```markdown
   ···
   这里是正文。
   ···
   ```

2. 点击左侧功能区的铅笔图标，打开写作面板。
3. 点击计时区的播放按钮开始写作计时；再点一次停止，计时和对手字数会停住。
4. 总览右上角的小眼睛可以隐藏编辑器里的 `···` 标记行。
5. 点“导出 Markdown”，会在当前笔记的同目录生成一份追踪报告。
6. 在插件设置里可以修改对手昵称、对手时速，以及是否在状态栏显示字数。

## 说明

- 只会追踪前两行 `···` 之间的内容。
- 数据统计只统计开始追踪后输入的字，打开文件时已经存在的内容不计入输入。
- 英文字母不参与统计。
- “重置”会清空当前文件的累计数据和总览，重新从当前正文开始记录。
- 仅支持 Obsidian 桌面端。
