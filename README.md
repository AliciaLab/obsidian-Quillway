# Quillway

追踪中文小说写作过程，自动记录你小说每一段增删字数、不同版本，用于回顾创作历史、检查字数存留率。

## 功能

- **拼字竞速**：与一名以特定速度创作的虚拟拼字对手PK。

- **字数统计**：状态栏里显示字数统计，以 Word 的规则计算字数。

- **时速统计**：原始时速统计无删改的打字速度，实际时速则计算删改的字数。

- **数据统计**：显示累计输入、累计删除、最终保留和留存率。

- **写作总览**：保留区域内每一段的删改历史，计算每一段内容的增字、删字和存留率。

- **修改版本**：记录每一段话的因增删字产生的不同版本。

- **导出 Markdown**：把当前文件的统计、总览和版本记录导出到笔记同目录。

- **隐藏分隔行**：用于标记写作区域的 `···` 行可以一键隐藏。


## 使用

1. 启用插件后，在笔记里写两行单独的 `···`，把你的写作内容放在这两行之间：

   ```markdown
   ···
   这里是正文。
   ···
   ```

2. 点击功能区的图标，打开面板。
3. 点击计时按钮，开始和停止写作计时。
4. 点击总览旁边的小眼睛图标，隐藏编辑器里的 `···` 标记行。
5. 点“导出 Markdown”，在当前笔记的同目录生成一份追踪报告。
6. 在插件设置里可以修改对手昵称、对手时速，以及是否在状态栏显示字数。

## 说明

- 只会追踪前两行 `···` 之间的内容。
- 数据统计只统计开始追踪后输入的字，打开文件时已经存在的内容不计入输入。
- 英文字母不参与统计。
- “重置”会清空当前文件的累计数据和总览，重新从当前正文开始记录。
- 仅支持 Obsidian 桌面端。

## 安装 
- 将装有main.js、style.css、mainfest.json的文件夹，放进plugin目录下。
- 使用BRAT插件拉取地址。
